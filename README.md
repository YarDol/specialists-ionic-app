# Specialists App

## Requirements

- **Node.js**: v20.17.0+

## Launch

### Backend

```bash
cd backend
npm install
npm start:dev
```

Backend: `http://localhost:3001`

### Frontend

```bash
cd ionic-app
npm install
npm run dev
```

Frontend: `http://localhost:5173`

### Mobile App (iOS)

```bash
cd ionic-app
npm run build
npx cap sync ios
npx cap open ios
```

### Swagger

Swagger: `http://localhost:3001`
